# REQUIREMENTS：功能清单与用户场景

## 1. 项目名称

序号 21：多模型协作翻译与审校系统。

## 2. 用户角色

| 用户 | 使用目标 |
|---|---|
| 学生/译者 | 对同一段文本获取两个模型译文，并选择质量更高的译文 |
| 审校人员 | 查看译文扣分明细、信达雅评价和修改建议 |
| 教师/评审 | 检查复杂度评估、规则评分、模型耗时统计是否可复现 |

## 3. 核心功能

### F1 文本复杂度评估

- 输入：一段待翻译文本。
- 输出：句子数量、平均句长、嵌套从句数、术语命中、术语密度、复杂度总分。
- 评估维度：句子长度、嵌套从句数、专业术语密度。

### F2 路由决策

- 低复杂度：快速双译对比。
- 中复杂度：双模型 + 术语提示 + 审校。
- 高复杂度：强制术语表 + 严格审校。

### F3 多模型翻译

- 同一原文调用模型 A 和模型 B。
- 支持真实 OpenAI 兼容接口。
- 支持 MOCK_MODE 离线演示，保证无 Key 也能跑通流程。

### F4 审校评分

至少 5 条量化扣分规则，本项目实现 8 条：

1. 数字/单位遗漏：每处扣 8 分，最多 24 分。
2. 专业术语不一致：每处扣 6 分，最多 30 分。
3. 源语残留偏多：残留比例 15%-30% 扣 10 分，超过 30% 扣 20 分。
4. 译文长度异常：过短扣 15 分，过长扣 8 分。
5. 标点/括号结构错误：每类扣 5 分，最多 15 分。
6. 专有名词/缩写遗漏：每处扣 4 分，最多 12 分。
7. 重复/语病：每处扣 5 分，最多 15 分。
8. Markdown 结构丢失：标题或列表减少时扣分。

### F5 推荐译文

- 按规则总分优先选择。
- 分数相同看“信”评分。
- 仍相同则选择耗时更短的模型。

### F6 审校子 Agent

- 输出“信、达、雅”三项评分。
- 根据信息遗漏、术语错误、结构问题生成修改建议。

### F7 图片 OCR 翻译

- 上传图片。
- pytesseract 提取文字。
- OCR 文本进入同一翻译审校流程。

### F8 Markdown 批量翻译

- 保持标题层级、列表、表格、代码块。
- 正文逐段翻译。
- 输出翻译后的 Markdown。

### F9 模型调用统计

- 记录模型名称、耗时、输入 token 估算、输出 token 估算、估算成本。
- 按模型汇总调用次数、总耗时和总成本。

## 4. 优先级

| 优先级 | 功能 |
|---|---|
| P0 | 复杂度评估、双模型翻译、规则评分、推荐译文 |
| P1 | 审校子 Agent、10 段评测、调用统计 |
| P2 | OCR、Markdown 批量翻译、下载评测结果 |
