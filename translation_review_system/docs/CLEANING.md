# CLEANING：数据文件与清洗说明

## 1. 数据文件

| 文件 | 说明 |
|---|---|
| `data/term_glossary.csv` | 专业术语表，用于复杂度评估和术语一致性评分 |
| `data/benchmark_texts.jsonl` | 10 段不同领域的英文测试文本，用于模型对比评测 |

## 2. 术语表字段

| 字段 | 含义 |
|---|---|
| `source_term` | 源语言术语 |
| `target_term` | 目标语言标准译法 |
| `domain` | 术语领域 |

## 3. 清洗规则

1. 去除空行和空字段。
2. `source_term` 统一小写匹配，但原始 CSV 保留可读格式。
3. `target_term` 去除前后空格。
4. 同一源术语重复时，保留第一条人工确认译法。
5. benchmark 文本统一为 JSONL，每行包含 `id`、`domain`、`text`。

## 4. 数据来源说明

当前样例数据为人工构造的教学演示数据，覆盖科技、医学、法律、经济、商业、教育等领域。正式提交时可以补充真实来源，例如教材句子、公开新闻段落、课程论文摘要等，并在本文件中列出来源链接或书目信息。
